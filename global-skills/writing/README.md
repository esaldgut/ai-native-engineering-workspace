# writing — technical writing canon

Skills for the *prose* side of engineering: how technical communication reads, not what it
implements. One skill so far.

| Skill | What it does |
|-------|--------------|
| [`spanish-technical-tone-canon`](spanish-technical-tone-canon/SKILL.md) | A canon for technical writing in Spanish (México / Latam neutral) — no spanglish (castellanized English verbs like `mergear` → `hacer merge`), no voseo, no unnecessary anglicisms, while keeping technical terms in English. Includes a conversion table, detection regex for a pre-publish pass, and the exemptions (literal quotes, code, API names). |
